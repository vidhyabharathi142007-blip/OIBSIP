# OIBSIP
Exploratory Data Analysis of Retail Sales Data using Python, Pandas, Matplotlib and Seaborn.

This repository contains the projects and tasks completed as part of the **Oasis Infobyte Internship Program (OIBSIP)** in Data Analytics.

## Tasks Completed

### Task 1 – Exploratory Data Analysis of Retail Sales Data

* Performed data cleaning and exploratory data analysis.
* Analyzed sales trends, product categories, customer demographics, and other key patterns.
* **Tools:** Python, Pandas, Matplotlib, Seaborn

### Task 2 – Customer Segmentation

* Analyzed customer purchasing behavior and performed customer segmentation.
* Identified different customer groups based on their purchasing patterns.
* **Tools:** Python, Pandas, NumPy, Matplotlib, Scikit-learn


### Task 4 – Sentiment Analysis

* Cleaned and preprocessed textual data.
* Applied TF-IDF vectorization for converting text into numerical features.
* Built and evaluated a machine learning model for sentiment classification.
* Saved the cleaned dataset.
* **Tools:** Python, Pandas, Scikit-learn, NLTK, Jupyter Notebook
