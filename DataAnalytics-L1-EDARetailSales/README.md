# Retail Sales EDA

Project: Exploratory Data Analysis (EDA) for a retail sales dataset.

This repository contains a CSV dataset and a Jupyter notebook performing EDA, visualizations, and summary statistics to help understand sales patterns.

Contents
- `retail_sales_dataset.csv` — primary dataset used for analysis.
- `Retail_Sales_EDA.ipynb` — Jupyter notebook with the step-by-step EDA and visualizations.

Getting started

1. Create and activate a Python virtual environment (recommended):

```
python -m venv .venv
.\.venv\Scripts\activate
```

2. Install commonly used data libraries:

```
pip install pandas numpy matplotlib seaborn jupyter
```

3. Open the notebook:

```
jupyter notebook Retail_Sales_EDA.ipynb
```

Notes
- The notebook is self-contained and documents assumptions and steps.
- If you need additional plotting interactivity, consider installing `plotly` or `altair`.

Project structure

- `retail_sales_dataset.csv` — input data (rows: transactions or aggregated sales by period).
- `Retail_Sales_EDA.ipynb` — analysis and visualization notebook.
- `README.md` — this file.
